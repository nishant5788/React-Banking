# 🏦 React Banking

A modern banking app built with React and the `useReducer` hook to practice complex state management and reducer patterns.

---

## 🚀 Features

- Open and close bank account
- Deposit and withdraw money
- Request and repay loans
- State management using `useReducer`
- Responsive and modern UI
- Loan and balance tracking

---

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- CSS
- useReducer Hook
